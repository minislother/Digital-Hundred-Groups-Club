# 数字百团 Android 发布资料

## 应用名称

数字百团

## 一句话简介

面向校园社团的移动端信息浏览、申请入团和活动报名工具。

## 简短描述

数字百团帮助学生在手机上浏览校园社团、查看活动、提交入团申请并跟进申请状态。

## 完整描述

数字百团是校园社团管理系统的 Android 学生端。学生可以使用学号登录，浏览热门社团和近期活动，查看社团与活动详情，提交加入社团或报名活动申请，并在个人中心查看自己的社团、活动和申请记录。

主要功能：

- 学生登录与注册
- 社团列表、搜索和详情
- 活动列表、搜索和详情
- 入团申请和活动报名
- 我的社团、我的活动、我的申请
- 下拉刷新和分页加载

## 默认分类

教育 / 校园服务

## 内容分级建议

适合所有用户。应用内容以校园社团信息、活动报名和学生个人申请记录为主。

## 隐私与数据说明

应用会使用以下数据：

- 学号：用于登录和识别学生身份
- 邮箱：用于注册验证码
- 手机号、专业、个人简介：用于申请信息展示
- 申请记录：用于展示入团和活动报名进度

发布前需要准备正式隐私政策 URL，并确保后端生产环境启用 HTTPS。

## 发布前检查

- 确认 `BAITUAN_RELEASE_BASE_URL` 指向 HTTPS 生产后端
- 确认 release 使用正式签名证书
- 确认应用图标、启动页、应用名称显示正常
- 使用 Android Studio 生成 AAB
- 在 Play Console 或目标应用市场填写隐私政策、截图和数据安全信息
