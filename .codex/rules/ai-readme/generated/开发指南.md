## 调试与验证
```text
MySQL club + Redis -> Spring Boot :8081 -> Vue dev server -> 浏览器页面
```

- 后端默认端口为 `8081`。
- 三个前端开发环境默认请求 `http://localhost:8081`。
- 后端统一响应结构由 `Result` / `PageUtils` 生成，前端按 `code === 20000` 判断成功。
- 如果需要 Kafka，检查 `spring.kafka.bootstrap-servers` 与 `app.kafka.enabled` 等配置；当前配置默认关闭业务监听。
