# 开发指南

## 环境准备
| 工具 | 版本 | 来源 |
| --- | --- | --- |
| JDK | 17，后端 Maven 编译目标 16 | `club_springboot/pom.xml`、`baituan_android/app/build.gradle.kts` |
| Maven | 3.8+ | 后端构建命令 |
| Node.js / npm | Node 18+ 建议；项目脚本按 npm 编写 | 根 `package.json` 与各前端 `package.json` |
| MySQL | 8.x 建议 | `application.properties`、`club_finalversion.sql` |
| Redis | 本地 `127.0.0.1:6379` 默认 | `application.properties` |
| Kafka | 默认 `localhost:9092`，业务监听默认可关闭 | `application.properties` |
| Android Studio | 支持 AGP 与 Kotlin Compose | `baituan_android/` |

USE club;
SOURCE D:/JavaPrograms/baituan/club_finalversion.sql;

## 后端环境变量
| 变量 | 示例 | 说明 |
| --- | --- | --- |
| `DB_URL` | `jdbc:mysql://localhost:3306/club?...` | 数据库连接 |
| `DB_USERNAME` | `root` | 数据库用户名 |
| `DB_PASSWORD` | `123456` | 数据库密码 |
| `JWT_SECRET` | 至少 32 位随机字符串 | JWT 签名密钥 |
| `KAFKA_ENABLED` | `false` | 是否启用 Kafka 业务能力 |
| `REDIS_HEALTH_ENABLED` | `false` | 本地健康检查是否纳入 Redis 状态 |
| `RATE_LIMIT_FAIL_OPEN` | `true` | Redis 限流不可用时是否放行请求 |

## 注意事项
- 当前机器如果 `npm` 未加入 PATH，需要先把 Node.js 安装目录加入系统 PATH。
- 如果旧静态服务占用 `9529/9530`，不要把统一入口继续指向这两个端口；当前管理员端和超级管理员端开发端口已改为 `9531/9532`。
- `outputs/` 是本地输出产物目录，不应作为普通源码提交。
