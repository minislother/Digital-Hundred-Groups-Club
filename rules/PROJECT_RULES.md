# Project Rules

本文件用于记录 `baituan` 项目的通用工作规则。

## General

- 修改项目前先阅读 `AGENTS.md`。
- 优先保持现有目录结构、框架和代码风格。
- 不要回滚用户已有改动。
- 不要修改无关文件。
- 不要把 `.idea/`、`target/`、`node_modules/`、日志、临时 diff 文件当作业务改动。

## Context

- 后端目录：`club_springboot/`
- 管理员前端：`vue_admin/`
- 学生端前端：`vue_student/`
- 超级管理员前端：`vue_superadmin/`
