# Security Rules

本文件用于记录项目安全相关规则。

## Secrets

- 不要把数据库密码、邮箱授权码、JWT 密钥、API key 写入源码。
- 使用环境变量、本地私有配置或配置中心管理敏感信息。
- 如果发现已提交的密钥，优先提示需要更换密钥。

## Authentication

- 非公开接口必须校验登录态。
- 涉及学生、管理员、超级管理员的接口必须校验角色权限。
- 不信任前端传入的用户编号作为身份来源。

## Files

- 上传文件必须校验大小、扩展名、MIME 和路径。
- 下载文件必须校验路径不能逃逸上传目录。
- 不允许通过文件名读取任意服务器文件。

## Frontend

- 密码和 token 不应通过 URL query 参数传输。
- token 存储需要考虑 `Secure`、`SameSite`、过期时间和 XSS 风险。
